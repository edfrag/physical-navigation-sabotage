# Results layout

- `offline/`: JSON/CSV outputs from AOPP, Random, PathBlock, min-cut, chokepoint, and betweenness experiments.
- `gazebo/`: per-trial Nav2/Gazebo telemetry and summaries.
- `hardware/`: TurtleBot4 outcomes and rosbag recordings/metadata.

The camera-ready manuscript reports aggregate results, but the original per-trial files cannot be reconstructed from those aggregates. Copy the archived experiment outputs into these directories rather than generating synthetic replacements.
