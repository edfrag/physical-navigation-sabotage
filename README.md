# Physical Navigation Sabotage

Companion artifact for *Physical Navigation Sabotage: Trusted-Input Attacks on
Robot Navigation* (ACSAC 2026).

This repository contains the recovered experiment code, occupancy-grid maps,
and recorded offline, Nav2, and Gazebo outputs. See [SUMMARY.md](SUMMARY.md)
for the evidence index and [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for commands.

Hardware per-trial records and exact placement metadata are not included.
Some archived planner outcomes remain unresolved; the original records are
preserved without reclassification.
